# Rtings Calculate

将现有 Rtings TV 评分 Excel 转化为可追溯、可配置、可对比的评分工具。先交付 Web 端，验证评分逻辑与使用体验后，再复用核心能力落地微信小程序。

## 当前状态

- 阶段：多机型对比 / 规则融合 / 云端架构设计
- Web 进度：首页多机型对比、产品介绍、历史机型追溯、测试项对比、评分录入、Excel 导入
- 评分规则：已接入融合版 v3，支持 CSV 锚点插值、类别/恒等映射、缺失重归一与 107 款真实数据回归
- 云服务：已开通并接入评测快照云表；评分录入页可保存到云端历史库
- 云端历史：支持查看历史输入、载入修改、导出完整 Excel（含总览图表）
- 本地保存：除云端外支持保存到本机历史库，可载入/删除
- 图表增强：新增顶层贡献对比、历史机型优势/短板排行
- 文档入口：
  - `docs/requirements.md`
  - `docs/scoring-rules.md`
  - `docs/export-templates.md`
  - `docs/deployment.md`
  - `docs/data-architecture.md`
  - `docs/project-log.md`

## 核心目标

1. 录入客观测试值与主观评分，计算 Mixed Usage 总分及各层子项分。
2. 每个结果均可逐层追溯到输入、映射区间、公式、权重和舍入过程。
3. 得分区间可维护、可验证、可追溯版本，修改规则不污染历史评测。
4. 支持 Excel 导出、图表展示，以及多产品总分/子项/测试项对比。
5. 评分核心与 UI 解耦，便于后续接入其他系统与微信小程序。

## 文档入口

| 文档 | 用途 |
|---|---|
| `docs/requirements.md` | 需求边界、确认状态、验收口径与信息架构 |
| `docs/scoring-rules.md` | 从源工作簿提取的评分规则、证据与异常 |
| `docs/export-templates.md` | Excel/PNG 导出模板与字段设计 |
| `docs/deployment.md` | 本机部署、内网部署和后续集成方案 |
| `docs/project-log.md` | 已确认决策和项目阶段变化，只记录长期有效信息 |

文档分工不重复：需求看 `requirements`，计算事实看 `scoring-rules`，当前进度看本文件，历史决策看 `project-log`。

## 协作约束

- 不凭空补全 Rtings 规则；事实、推断、待确认项必须分开标记。
- 评分引擎优先使用独立、可测试的规则模块，不把公式散落在页面组件中。
- 小步提交；每个可验证阶段同步更新文档。
- 单个源文件原则上不超过 200 行，超出时优先拆分职责。
