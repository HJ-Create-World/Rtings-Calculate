# Rtings Calculate

将现有 Rtings TV 评分 Excel 转化为可追溯、可配置、可对比的评分工具。先交付 Web 端，验证评分逻辑与使用体验后，再复用核心能力落地微信小程序。

## 当前状态

- 阶段：需求确认与评分规则拆解
- 业务代码：尚未开始
- 源工作簿：`Rtings计算文档.xlsx`（仅作只读规则来源，不修改）
- 开发闸门：评分歧义与产品需求经 HJ / 工程师确认后，才进入实现

## 核心目标

1. 录入客观测试值与主观评分，计算 Mixed Usage 总分及各层子项分。
2. 每个结果均可逐层追溯到输入、映射区间、公式、权重和舍入过程。
3. 得分区间可维护、可验证、可追溯版本，修改规则不污染历史评测。
4. 支持 Excel 导出、图表展示，以及多产品总分/子项/测试项对比。
5. 评分核心与 UI 解耦，便于后续接入其他系统与微信小程序。

## 文档入口

| 文档 | 用途 |
|---|---|
| `docs/requirements.md` | 需求边界、验收口径与待确认问题 |
| `docs/scoring-rules.md` | 从源工作簿提取的评分规则、证据与异常 |
| `docs/project-log.md` | 已确认决策和项目阶段变化，只记录长期有效信息 |

文档分工不重复：需求看 `requirements`，计算事实看 `scoring-rules`，当前进度看本文件，历史决策看 `project-log`。

## 协作约束

- 不凭空补全 Rtings 规则；事实、推断、待确认项必须分开标记。
- 评分引擎优先使用独立、可测试的规则模块，不把公式散落在页面组件中。
- 小步提交；每个可验证阶段同步更新文档。
- 单个源文件原则上不超过 200 行，超出时优先拆分职责。
