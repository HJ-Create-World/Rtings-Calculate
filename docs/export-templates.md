# 导出模板设计

状态：规划确认稿，按 P07/P08 口径设计。首版先实现已具备的数据导出，再逐步补齐模板配置。

## 1. 设计目标

1. 导出的 Excel 能独立复核：不只给最终分，还包含输入值、命中区间、权重和警告。
2. 支持企业汇报：对比汇总清晰、图表可另存 PNG、明细可追溯。
3. 支持模板配置：字段顺序、Sheet 开关、数字精度和语言文案后续可配置。
4. 不做伪装数据：缺失、不计分、跨规则版本都显式标记。

## 2. Excel 模板清单

| 模板 | 场景 | Sheet | 关键字段 |
|---|---|---|---|
| 导入模板 | 工程师批量录入 | `产品信息`；每个顶层分组一个 Sheet；`导入说明` | 节点ID、维度/父级、测试项、类型、单位/范围、填写说明、值、备注 |
| 单机评测报告 | 单个产品正式留档 | `产品信息`、`评分汇总`、`测试项明细`、`计算追踪`、`警告与状态` | 品牌/型号/日期/工程师；总分、分组分、维度分、叶子分；输入、命中区间、权重、贡献 |
| 多产品对比报告 | 2~6 个产品汇报 | `对比汇总`、`顶层分组对比`、`测试项对比`、`产品档案` | 产品名、总分、各分组分、节点级得分、缺失状态、规则版本 |
| 规则快照导出 | 规则版本留档 | `节点清单`、`权重表`、`区间表`、`校验结果` | 节点ID、层级、权重、计入父项、单位、方向、区间边界、开闭规则、来源 |

## 3. 必含口径

| 字段/标记 | 规则 |
|---|---|
| 规则版本 | 每个数据 Sheet 都带 `规则版本`，避免跨版本误读 |
| 分数精度 | 计算内部保留全精度；Excel 展示 1 位小数，必要时提供原始精度列 |
| 权重精度 | 权重显示为百分比；保留 `1.0004` 这类异常并在警告中说明 |
| 缺失值 | 显示“未填写”，不填 0，不插值 |
| 不计分项 | 显示 `不计入`，保留原始测试值 |
| `inf` | 保留为文本 `inf`，导入解析为无穷大 |
| 跨版本对比 | 单独 Sheet 或列标记规则版本；不同版本显著警告 |
| 计算证据 | 每个叶子分保留输入值、命中区间、分数档、来源和警告 |

## 4. 模板配置

后续增加模板配置，而不是把字段顺序写死在组件里：

```json
{
  "id": "comparison-standard-v1",
  "scope": "comparison",
  "sheets": [
    { "key": "summary", "enabled": true },
    { "key": "groupComparison", "enabled": true },
    { "key": "testItemComparison", "enabled": true },
    { "key": "productMeta", "enabled": true }
  ],
  "numberFormat": {
    "score": "0.0",
    "weight": "0.00%"
  },
  "columns": {
    "summary": ["product", "total", "ruleVersion", "status"]
  }
}
```

配置校验要求：

- `scope` 必须是 `single`、`comparison`、`trace`、`rule` 之一。
- 不允许关闭 `ruleVersion` 和关键状态字段。
- 数字格式只能调整展示精度，不能改变核心计算。
- 模板配置变更要生成新版本，历史导出文件保留所用模板 ID。

## 5. PNG / 图表导出

| 图表 | 导出内容 |
|---|---|
| 总分柱状图 | 当前选中产品的总分对比 |
| 顶层能力雷达图 | 当前选中产品的顶层分组轮廓 |
| 测试项对比图 | 当前选中分组、测试项和产品的节点级对比 |

导出要求：

- 使用当前浏览器 Canvas 渲染，白底 PNG。
- 文件名带场景和日期，例如 `Rtings-多产品总分对比-2026-11-05.png`。
- 图表下方数据仍以 Excel 为准；PNG 用于汇报展示。
