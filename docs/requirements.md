# 产品需求与确认清单

状态：草稿，待 HJ 与工程师确认。本文描述产品边界；具体评分事实与单元格证据见 `scoring-rules.md`。

## 1. 目标用户与核心流程

用户：填写 TV 测试数据、主观评分并核对 Rtings 评分的工程师，以及维护评分规则的规则管理员。

核心流程：新建产品评测 → 填写客观测试值和主观分 → 校验缺失/异常输入 → 计算总分与子项分 → 展开计算过程 → 保存评测 → 导出或横向对比。

## 2. 首版建议范围（MVP）

| 模块 | 首版能力 | 验收重点 |
|---|---|---|
| 评测录入 | 按评分层级组织表单；标识必填、NA、主观项、单位和异常值 | 录入不迷路，草稿可保留 |
| 评分计算 | 输出 Mixed Usage、各级子项与测试项得分 | 与确认后的 Excel 基准案例一致 |
| 计算追溯 | 展示输入值、命中区间、映射分、权重、公式、舍入和警告 | 每一分都能解释来源 |
| 规则管理 | 修改区间与权重；校验重叠/空洞；版本化；历史评测绑定旧版本 | 改规则不改写历史 |
| 数据管理 | 保存产品评测、查看详情、复制评测、重新计算 | 刷新不丢数据，重算有记录 |
| 导出 | 导出总评、子项、测试项、输入值、计算警告和规则版本 | Excel 内容完整、可复核 |
| 图表与对比 | 总分、子项、具体测试项的多产品对比 | 同口径对比，差异可定位 |
| 文档与测试 | 规则文档、需求文档、基准案例和自动化测试同步更新 | 换 AI/开发者可顺利接手 |

首版不建议加入自动抓取 Rtings 网站、AI 自动推断主观分、复杂审批流等外围功能，以免稀释评分正确性验证。

## 3. 关键设计原则

### 3.1 计算与界面分离

评分核心应是独立、无副作用的模块：同一组输入和同一规则版本必须得到同一结果。Web、后续小程序和其他系统不得各自复制一套公式。

### 3.2 规则版本与证据快照

每次评测保存规则版本、输入快照、计算结果和逐步追踪。规则修改产生新版本；是否用新版本重算历史评测由用户显式触发，并保留记录。

### 3.3 缺失不等于零分

无实测点、无预估区间、输入未填写、测试项 NA 是不同状态，不能统一转成 0。计算结果需区分实测映射、区间推断、人工评分、缺失和排除项，并显示可信度/警告。

缺失区间建议提供两种明确模式，而不是隐式猜测：

| 模式 | 行为 | 用途 |
|---|---|---|
| 严格模式 | 无法映射则该测试项标为“待确认”；按确认后的父项规则阻止正式总分或标记不完整 | 正式评测、对外导出 |
| 估算模式 | 仅在工程师批准的规则下插值/补区间；结果显著标记“估算”，保留所用规则 | 内部预判、规则完善 |

默认不建议自动外推，也不建议用最近评分档位强行覆盖空洞。每个区间至少应记录：上下限、开闭边界、得分、来源（实测/工程师预估/人工补充）、规则版本和备注；发布前自动检查重叠、空洞、方向和单位异常。

### 3.4 先保证正确，再优化展示

建立一组经工程师签字确认的“输入 → 各层结果”基准案例，作为开发与后续改规则的回归标准。图表不能替代计算明细。

## 4. Web 到小程序的边界建议

优先考虑共享评分核心与统一数据/API，而不是先做一套 Web 公式、后再为小程序重写。小程序侧重点为移动录入、查看和对比；复杂规则维护、批量导出可保留在 Web 管理端。

是否首版即建设服务端，取决于第 5 节中的部署、多人协作和数据共享答案。

### 5.1 联网能力边界

- 完全离线可用：评分计算、表单录入、图表展示、PNG 导出、本地 Excel 导出。
- 需要网络的能力只包括：后续部署到内网服务器时的远程访问、后续接入项目管理系统、如有远端备份/同步。
- 不引入公网 LLM、云数据库、在线字体、在线图标库等运行时强依赖。

## 6. Web 信息架构与展示原则

为避免单页过长、图表挤压，采用分页式工作台：

| 页面 | 定位 | 主要内容 |
|---|---|---|
| 评分总览 | 快速结论 | 权威基准总分、规则健康度、关键警告、核心指标 |
| 横向对比 | 产品报告 | 2~6 个产品总分柱状图、顶层能力雷达图、对比表、Excel/PNG 导出 |
| 自定义下钻 | 工程师分析 | 选择顶层分组、测试项和产品；测试项级柱状/雷达对比 |
| 单机追溯 | 排查与展示 | 单产品总分、子项、计算证据、输入/权重/区间/警告 |

图表原则：对比页图表使用大高度；下钻页根据选中测试项数量自适应高度；图表和明细不挤在同一卡片内。

## 6. 评分核心最低验收案例

| 案例 | 必须验证的行为 |
|---|---|
| 完整基准评测 | 每个层级的中间值与最终结果均与工程师确认值一致 |
| 区间边界 | 恰好等于上下限、跨边界、超出量程时命中规则明确 |
| NA 与不计分项 | 保留测试记录但不参与加权，不误当作缺失或零分 |
| 未填写与无法映射 | 明确显示缺失状态及其对总分的影响，不静默补零 |
| 主观评分 | 输入范围、精度、权重及追溯路径与客观项一致可查 |
| 权重变化 | 校验权重合法性；历史版本结果保持不变 |
| 舍入 | 中间层是否保留全精度、仅展示层舍入符合确认口径 |
| 重复计算 | 同输入 + 同规则版本得到完全一致的结果和追踪 |
| 导出复核 | 导出数据可独立还原总分，不只包含最终分数 |
| 跨产品对比 | 不同规则版本、缺失项和单位差异有明确提示 |
