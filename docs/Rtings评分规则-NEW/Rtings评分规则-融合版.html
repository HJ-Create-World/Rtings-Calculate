类别型（30 项 ✅A）

Native Refresh Rate60Hz→0；120/144/165/180Hz→9.5
4k/1080p VRR Minimum<20Hz→10；48Hz→6.6；40Hz→7；不支持→0

Local Dimming / Color CalibrationYes→10 / No→0
Screen Finish / ResolutionGlossy/Matte 均→10；4k/8k 均→10

恒等映射（19 项 ✅A）

Smoothing、Detail Preservation、8 项 Gradient、7 项 Judder、Edge/Color Artifacts —— 得分=原始值。

数值曲线（75 项 ✅A）

线性插值锚点表实现（JSON leafScales.numericAnchors，每项≤30 锚点，含方向 increasing/decreasing）。示例：Hallway 185→1.6 … 2085→10；Native Contrast 941→3.9 … Inf→10；WB dE 0.6→9.5 … 8.84→0.4。范围外无数据支撑。

主观/半主观（👤D）

Upscaling: Sharpness Processing无原始量，人工评级。锚点：7分≈MTK9615(TCL QM6K/Q77K)，8分≈MTK9618(Sony X90L级)
Lighting Zone Precision / Transitionsscore-only；按分区数+光晕表现评估（65寸≥160区起）
Black Uniformity半主观（含人工判读），子项 Std.Dev 有客观量
HDR Photo 对比项 ×3未启用（全表无数据）

废弃/未启用（不计分）

Gamma×2、FreeSync、Black Luminance@0lx、BU Picture（恒0分）；Native BU Picture、HDR Photo×3、LZP Picture（无数据）。

5. 实现注意事项

  • 单位：黑场 Std.Dev CSV 为百分数（1.857=1.857%），实验室小数需 ×100；Contrast 为比值。
  • 缺席 vs 0 分：不做 renormalize 会系统性压低低配产品 2+ 分（60Hz 机型残差证实）。
  • 数据恒同列：480p≡4k@60、1080p444≡4k60444、4k120≡4k120444、MicroJudder native 24p≡25p。
  • Game Mode：先用工程师结构，自测数据积累后回归校准（CSV 缺 CAD@60 无法验证）。
  • 本文件无编造数值：所有权重/门槛/锚点均可溯源（CSV 反推附验证误差；工程师表附证据等级）。
